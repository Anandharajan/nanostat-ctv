nanostat

Learn how today's AI agents are trained with verifiable rewards — on a problem small enough to see every number. A tiny agent must pick a statistical test. Code runs the test. Rewards decide what it learns. Everything below runs in your browser.

1 · When do statistical tests lie?

Simulate 500 datasets where nothing is going on. A trustworthy test should cry "significant!" only about 5% of the time.

Try two_group/unequal_var (Student's t lies) and correlation/outliers (Pearson lies badly).

2 · Two ways to reward an agent

Fisher-style: "your p-value should be close to the reference p-value." CTV: "your method must be one of the defensible ones; invalid methods are penalised." Rows highlighted are invalid methods that the Fisher-style reward still pays well.

3 · Train a tiny agent with each reward (same compute)

Both agents start with a "textbook" habit (always the classic parametric test). Each step samples 8 plans for 8 tasks, scores them, and nudges the policy toward above-average plans (GRPO). Both arms generate exactly the same number of plans. Averaged over 5 seeds, after 25 steps the CTV agent picks a defensible test on ~72% of tasks vs ~55% for the Fisher-style agent; both approach 100% by ~100 steps in this easy world. The full GPT version is in lesson 8.
