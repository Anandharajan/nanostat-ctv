# Data card — NanoStat-Bench (synthetic), generator 0.1.0

- **Source:** fully synthetic, generated by `benchmark/factory` with seeded NumPy generators. No third-party data.
- **Families:** independent two-group (continuous, binary), paired, correlation, k-group, one-sample proportion; plus model-based families (v0.4): linear, binary, IV, multi-arm restriction, survival by group, Cox, panel (see docs/REGRESSION_FAMILIES.md).
- **Grid:** family × sample-size regime {small, medium, large} × effect {null, borderline, medium, large} × perturbation × prompt style {hint, no_hint} × claim {two-sided, greater, less} × domain template (5) × seed.
- **Twins:** design flip (independent↔paired), add outliers, tail flip, small expected counts, remove pairing ID, outcome type (continuous→binary), estimand change (mean↔typical), and spec twins for model-based families (add clustering, add confounder, make endogenous). Wording-fixed and wording-changed kinds. `outcome_type` and `small_counts` are held out for the test split only.
- **Splits:** by hashed scenario/template lineage; twins share a split.
- **Answer keys** (`keys/keys.jsonl`): admissible set A(x), invalid set B(x) with cached p-values, reference decision, DGP truth, discordance, twin links. Never shown to the agent; git-ignored.
- **Regenerate:** `nanostat factory --profile smoke|pilot|full --out data --seed 20261126`. The factory is deterministic for a given seed and version (tested).
- **Known gaps:** no missing-data mechanisms or ordinal outcomes; clustering, confounding, endogeneity and censoring exist only in the model-based families; no stacked/reshaped designs (P-Bench `other`).
